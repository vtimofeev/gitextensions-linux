# Проверка кода в терминале

[English](code-review.md) | Русский

Откройте **Проверить коммит…** в меню графа либо проверку незафиксированных изменений в боковой панели.
Выберите Codex, Claude, Qwen или OpenCode, задайте инструкции и описание задачи, затем нажмите **Начать** или `Ctrl+Enter`.
Инструмент запускается в отдельном терминале в каталоге репозитория; диалог не управляет его моделью или авторизацией.

Все инструменты доступны без предварительной проверки `PATH`. Команду или полный путь можно изменить в **Настройки → Проверка кода**.
Инструкции можно сохранить как стандартные. Детали задачи помнятся для репозитория и выбранного коммита до выхода из приложения.

## Шаблоны

| Подстановка | Значение |
| --- | --- |
| `{target}` | SHA коммита или `uncommitted` |
| `{instructions}` | Инструкции проверки |
| `{details}` | Описание задачи |
| `{prompt}` | Составленный запрос с целью и инструкциями чтения Git |
| `{promptFile}` | Путь к UTF-8-файлу с полным запросом |

Кавычки группируют аргументы. Подстановки выполняются внутри аргументов; shell-конструкции, конвейеры и раскрытие переменных окружения не исполняются.
Настроенный путь к инструменту заменяет первый аргумент шаблона. Совместимые прежние имена подстановок сохраняются.

Шаблон терминала должен содержать один отдельный аргумент `{command}`, например `gnome-terminal -- {command}` или `kitty {command}`.
Режим Auto выбирает доступный терминал. Ошибка его запуска отображается в приложении; ошибки самого инструмента — в терминале.

## Длинные запросы

Запрос также записывается в приватный файл в `$XDG_CACHE_HOME/gitextensions-linux/reviews` или системном каталоге пользовательского кеша.
При превышении 100 КиБ в аргументах описание задачи сокращается с предупреждением; инструкции не сокращаются молча.
Для передачи всего запроса используйте `{promptFile}` с поддерживаемым самим инструментом параметром чтения файла.
Файлы для таких шаблонов можно удалить после завершения терминальной сессии.
