# Руководство пользователя

[English](user-guide.md) | Русский

Установите приложение по [инструкции для Linux](linux-install.ru.md), затем запустите **Git Extensions Linux** из меню приложений.

## Открытие репозитория

Нажмите `Ctrl+O` и выберите существующий Git-репозиторий. Можно также передать путь при запуске:

```sh
~/.local/bin/gitextensions-linux --repo "/path/to/repository"
```

При запуске приложение открывает последний активный репозиторий. Путь, переданный при запуске, имеет приоритет.

Клонируйте или создайте репозиторий средствами Git до открытия; экрана clone/init в приложении пока нет.

## История и изменения

Выберите коммит в графе, чтобы просмотреть изменённые файлы и diff. Поиск и фильтр автора помогают сузить историю. История файла и blame показывают предыдущие изменения.

Изменённые файлы сгруппированы в дерево каталогов. Сворачивайте каталоги, чтобы сосредоточиться на именах файлов, и перетаскивайте разделитель для изменения ширины дерева. Действия просмотра расположены слева, путь выбранного файла — справа. Цепочки каталогов без разветвлений занимают одну строку, например `one/two/three`; при узкой панели сокращается середина пути, а последний каталог остаётся видимым. Стрелки вверх/вниз сразу открывают предыдущий/следующий файл, пропуская строки каталогов и при необходимости раскрывая путь. Кнопки предыдущего и следующего файла или `Alt+PageUp` / `Alt+PageDown` переключают файлы в панели diff. Для перехода между блоками изменений используйте кнопки предыдущего и следующего изменения или `Shift+F7` / `F7`.

Синхронизированные локальная и отслеживаемая удалённая ветки показаны общей подписью в графе. Название текущей ветки вместе с удалённой частью не сокращается; длинные названия доступны через горизонтальную прокрутку графа. Контекстное меню имени ветки или удалённой части открывает соответствующие действия.

Откройте локальные изменения для просмотра и добавления файлов в индекс или удаления из него. Эти операции работают с целыми файлами. Введите сообщение коммита и нажмите `Ctrl+Enter` для коммита или `Ctrl+Shift+Enter` для коммита с отправкой.

Сворачивайте блоки локальных веток, «В индексе» и «В рабочем дереве» стрелками в заголовках. Перетаскивайте разделители для изменения размеров панелей; размеры и свёрнутые состояния сохраняются. Иконка обновления рядом с заголовком «В индексе» обновляет статус файлов в обоих списках без перезагрузки истории. У файлов в индексе и рабочем дереве одна иконка типа файла, а статус передаётся её цветом и подсказкой.

Меню веток (`Ctrl+B`) содержит операции с ветками. Fetch, pull и push используют системные настройки Git, SSH-агент и средства хранения учётных данных.

## Настройки и сочетания клавиш

Откройте настройки через `Ctrl+,`, чтобы выбрать тему, язык интерфейса и профиль Git. Палитра команд (`Ctrl+K`) даёт быстрый доступ к действиям.

В blame переключатели «Показывать дату» и «Показывать время» позволяют оставить дату со временем, только дату или сведения об авторе без даты. Выбор сохраняется.

Для изображений доступны Fit, 100% и масштабирование через `Ctrl` + колесо мыши или кнопки `+` / `−`. Для SVG можно переключаться между изображением и исходным кодом.

Ошибки появляются внизу приложения поверх других окон; закрывайте их кнопкой ×. Для разрешения конфликтов используются внешние merge tools; встроенного редактора конфликтов пока нет.

## Обновление

Закройте приложение, распакуйте новый релиз и снова выполните `./install.sh`. Создание ярлыков и удаление описаны в [инструкции по установке](linux-install.ru.md).
