# Граф коммитов

[English](commit-graph.md) | Русский

Алгоритм размещения линий в `frontend/src/graph/layout.ts` адаптирован из `RevisionGraph.cs` и `RevisionGraphRow.cs` оригинального Git Extensions.
Тестовые схемы и ASCII-проверка происходят из `RevisionGraphTests.cs`. Эти материалы сохраняют **GPL-3.0-only**; атрибуция и ссылки — в [NOTICE.ru.md](../NOTICE.ru.md).

## Как работает адаптация

- Сохраняет всех родителей merge-коммита и их порядок; не загруженные родители остаются незавершёнными рёбрами.
- Объединяет линии с общим родителем и выпрямляет их с ограниченным просмотром следующих строк.
- Строит раскладку в Web Worker; смена запроса отменяет старый worker и отбрасывает запоздавшие ответы.
- Рисует Canvas размером с видимую область. DOM-строки виртуализированы; данные раскладки не оборачиваются в глубокие Vue-прокси.
- Поиск не подменяет отсутствующих родителей соседними найденными коммитами.

WinForms-отрисовка не переносилась: здесь Canvas, собственные цвета, масштабирование под DPR и Vue-подписи refs.
Маркер HEAD, текущая ветка и выбранный для diff коммит отображаются независимо.

Проверки: `frontend/tests/graph.test.ts`, `graph-fixtures/`, `pointers.test.ts`, `ref-labels.test.ts` и браузерные сценарии истории.
